## Description

`ft_printf` は、C 標準ライブラリの `printf` 関数の一部を再実装する
42 curriculum のプロジェクトです。

このプロジェクトの目的は、可変長引数を扱う方法を学びながら、
指定された変換指定子に応じて文字、文字列、数値、ポインタなどを
標準出力へ表示する関数を作成することです。

実装する関数のプロトタイプは以下です。

```c
int	ft_printf(const char *format, ...);
```

対応している変換指定子は以下です。

- `%c`: 1文字を出力する
- `%s`: 文字列を出力する
- `%p`: ポインタのアドレスを16進数で出力する
- `%d`: 10進数の整数を出力する
- `%i`: 10進数の整数を出力する
- `%u`: 符号なし10進数を出力する
- `%x`: 小文字の16進数を出力する
- `%X`: 大文字の16進数を出力する
- `%%`: パーセント記号を出力する

## Instructions

このプロジェクトは `Makefile` によってコンパイルできます。

```sh
make
```

実行すると、リポジトリのルートに `libftprintf.a` が作成されます。

使用例:

```c
#include "ft_printf.h"

int	main(void)
{
	ft_printf("Hello %s\n", "world");
	return (0);
}
```

オブジェクトファイルやライブラリを削除する場合は、以下のコマンドを使用します。

```sh
make clean
make fclean
make re
```

## Algorithm and Data Structures

`ft_printf` は、受け取った `format` 文字列を先頭から1文字ずつ走査します。
通常の文字はそのまま `write` で出力し、`%` を見つけた場合は次の文字を
変換指定子として判定します。

可変長引数は `va_list` を使って管理します。`va_start` で引数の読み取りを開始し、
変換指定子に応じて `va_arg` で適切な型の値を取り出します。
処理が終わったら `va_end` を呼び出します。

数値の出力では、10進数または16進数の基数で値を分解し、各桁を文字として出力します。
負の整数は先に `-` を出力し、正の値に変換してから各桁を処理します。

このプロジェクトでは複雑なデータ構造は使用していません。
主に使っているデータは、フォーマット文字列へのポインタ、可変長引数リスト、
出力した文字数を数えるための `int` 変数です。
これは `printf` の基本的な変換処理を実装するためには十分であり、
処理の流れを単純に保てるためです。
